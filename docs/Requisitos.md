# Requisitos do Sistema

## Introdução
Os requisitos a seguir definem as principais funcionalidades e restrições técnicas que o **Sistema de Gerenciamento de Academia** deve possuir para garantir seu correto funcionamento e atende às necessidades operacionais.

---

## Requisitos Funcionais (RF)

| Código | Requisito | Descrição |
| :--- | :--- | :--- |
| **RF01** | Cadastro de alunos | O sistema deverá permitir cadastrar novos alunos. |
| **RF02** | Consulta de alunos | O sistema deverá permitir consultar os alunos cadastrados. |
| **RF03** | Edição de alunos | O sistema deverá permitir alterar os dados dos alunos. |
| **RF04** | Exclusão de alunos | O sistema deverá permitir excluir alunos cadastrados. |
| **RF05** | Cadastro de professores | O sistema deverá permitir cadastrar professores. |
| **RF06** | Consulta de professores | O sistema deverá permitir consultar os professores cadastrados. |
| **RF07** | Cadastro de planos | O sistema deverá permitir cadastrar os planos oferecidos pela academia. |
| **RF08** | Consulta de planos | O sistema deverá permitir consultar os planos cadastrados. |
| **RF09** | Cadastro de exercícios | O sistema deverá permitir cadastrar exercícios. |
| **RF10** | Gerenciamento de treinos | O sistema deverá permitir criar, consultar e editar treinos dos alunos. |
| **RF11** | Controle de pagamentos | O sistema deverá permitir registrar e consultar os pagamentos dos alunos. |
| **RF12** | Identificação de pendências | O sistema deverá permitir identificar alunos com pagamentos pendentes. |
| **RF13** | Dashboard | O sistema deverá apresentar informações gerais da academia (quantidade de alunos, professores, planos e pagamentos pendentes). |

---

## Requisitos Não Funcionais (RNF)

| Código | Requisito | Descrição |
| :--- | :--- | :--- |
| **RNF01** | Usabilidade | O sistema deverá possuir uma interface simples, intuitiva e fácil de utilizar. |
| **RNF02** | Segurança | O sistema deverá proteger os dados dos usuários e controlar o acesso às funcionalidades. |
| **RNF03** | Desempenho | O sistema deverá apresentar as informações de forma rápida durante sua utilização. |
| **RNF04** | Compatibilidade | O sistema deverá funcionar nos principais navegadores modernos (Google Chrome, Firefox, Edge, Safari). |
| **RNF05** | Manutenibilidade | O sistema deverá possuir uma estrutura organizada para facilitar futuras alterações e melhorias. |
