# MVP - Sistema de Gerenciamento de Academia

## Objetivo
O MVP (Produto Mínimo Viável) tem como objetivo apresentar uma primeira versão funcional do sistema, contendo as principais funções necessárias para o gerenciamento básico de uma academia.

---

## Funcionalidades Incluídas

### 👤 Alunos
- Cadastrar aluno
- Consultar alunos
- Editar dados do aluno
- Excluir aluno

### 👨‍🏫 Professores
- Cadastrar professor
- Consultar professores
- Editar dados do professor

### 📋 Planos
- Cadastrar plano
- Consultar planos
- Editar plano

### 💰 Pagamentos e Treinos
- Registrar pagamento
- Consultar pagamentos
- Gerenciar / Editar treinos dos alunos

### 📊 Dashboard
- Visualizar quantidade total de alunos
- Visualizar quantidade total de professores
- Visualizar quantidade de planos cadastrados
- Visualizar pagamentos pendentes

---

## Resultado Esperado
Ao final do desenvolvimento do MVP, o sistema deverá permitir o controle e a gestão das principais informações operacionais da academia em um único ambiente integrado.
