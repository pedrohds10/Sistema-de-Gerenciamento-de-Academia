# Tecnologias e Ferramentas

Relação das tecnologias, linguagens, frameworks e ferramentas utilizadas no desenvolvimento do **Sistema de Gerenciamento de Academia**.

---

## 🎨 Front-end
- **HTML5:** Estruturação das páginas web
- **CSS3:** Estilização e layout responsivo
- **JavaScript:** Interatividade e comportamento dinâmico

---

## ⚙️ Back-end
- **Java:** Linguagem de programação principal
- **Spring Boot:** Framework para criação de APIs e serviços back-end

---

## 🗄️ Banco de Dados
- **MySQL:** Sistema de gerenciamento de banco de dados relacional

---

## 🐙 Versionamento
- **Git & GitHub:** Controle de versão e hospedagem do código-fonte

---

## 📐 Modelagem e Organização
- **UML:** Modelagem de diagramas e casos de uso do sistema
- **Google Planilhas:** Organização, estrutura e validação inicial dos dados

---

## Resumo das Tecnologias

| Categoria | Tecnologia / Ferramenta |
| :--- | :--- |
| **Front-end** | HTML5, CSS3, JavaScript |
| **Back-end** | Java, Spring Boot |
| **Banco de Dados** | MySQL |
| **Versionamento** | Git, GitHub |
| **Modelagem** | UML, Google Planilhas |
